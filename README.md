# Torre-de-Hanoi-com-Pilhas
O exercício requer o uso de pilhas, onde cada operação de movimentação utiliza exclusivamente push (inserção no topo) e pop (remoção do topo), garantindo o comportamento LIFO. Discos menores possuem valores inteiros menores
Como compilar e executar (Ambiente Linux)

Para rodar o simulador da Torre de Hanói utilizando Pilhas, certifique-se de ter o compilador `g++` e a ferramenta `make` instalados no seu sistema Linux.

**Passo a passo:**

1. Abra o terminal e navegue até a pasta onde os arquivos do projeto (`ex4.cpp` e `Makefile`) estão localizados.
2. Compile o código com o comando abaixo:
   ```bash
   make
   Com a compilação concluída, o executável ex4 será criado. Para iniciar a simulação dos movimentos, digite:
   ./ex4
